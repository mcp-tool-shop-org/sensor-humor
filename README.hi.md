एमसीपी टूल जो आपके एलएलएम को एक स्थायी हास्यपूर्ण साथी प्रदान करता है: मूड-आधारित व्यक्तित्व, सत्र-जागरूक कॉलबैक, लगातार चलने वाले चुटकुले, व्यंग्य, ताने और आकर्षक वाक्यांश - ये सभी पाइपर्स टीटीएस (लय-नियंत्रित) के माध्यम से आवाज एकीकरण के साथ।

डेवलपर्स के लिए बनाया गया: कोड की कमियों पर हल्की-फुल्की टिप्पणी, सरल और स्पष्ट त्रुटि संदेश, निर्माण विफल होने पर अराजक वृद्धि। यह कभी भी होस्ट एलएलएम की शैली को अधिलेखित नहीं करता है - एक विशिष्ट आवाज जो अनुरोध किए जाने पर प्रतिक्रिया देती है।

## विशेषताएं

- 6 मूड, प्रत्येक को अनुमानित, उच्च-गुणवत्ता वाले आउटपुट के लिए एक रिक्त स्थान भरने वाले टेम्पलेट प्रॉम्प्ट के साथ समायोजित किया गया है।
- सत्र स्थिति: लगातार चलने वाले चुटकुले, हालिया अंशों का रिंग बफर (अधिकतम 20), वाक्यांश मानचित्र - वैकल्पिक रूप से डिस्क पर संग्रहीत (`SENSOR_HUMOR_PERSIST`) ताकि कॉलबैक सर्वर रीस्टार्ट के बाद भी बने रहें।
- 11 उपकरण: मूड_सेट/मूड_गेट, कॉमिक_टाइमिंग, व्यंग्य, ताना, वाक्यांश_जनरेट/वाक्यांश_कॉलबैक, लगातार_चुटकुला, डिबग_स्टेटस, डिबग_चेन, सत्र_रीसेट।
- स्थानीय ओलामा बैकएंड (qwen2.5:7b डिफ़ॉल्ट, `SENSOR_HUMOR_MODEL` के माध्यम से कॉन्फ़िगर करने योग्य)।
- आवाज युग्मन: एमसीपी-वॉइस-साउंडबोर्ड पाइपर्स टीटीएस (लय नियंत्रण: लंबाई_स्केल, शोर_स्केल, शोर_डब्ल्यू_स्केल, वॉल्यूम)।
- नियतात्मक: जेएसओएन स्कीमा प्रवर्तन, सत्यापन, खराब आउटपुट पर पुनः प्रयास, मूड विरासत प्रवर्तन।

## मूड

प्रत्येक मूड एक रिक्त स्थान भरने वाले टेम्पलेट प्रॉम्प्ट का उपयोग करता है जो मॉडल को एक अनुमानित, उच्च-गुणवत्ता वाले रूप में मजबूर करता है।

- **सूखा** - सपाट, न्यूनतम, दर्दनाक रूप से स्पष्ट (डिफ़ॉल्ट)।
- **व्यंग्य** - स्नेही, तीक्ष्ण व्यंग्य, निर्णय/निदान लेबल।
- **निराशावादी** - निराश, शांत रूप से क्रूर यथार्थवाद ("निश्चित रूप से:", "अनुमानित रूप से:")।
- **शरारती** - चंचल, मजाकिया शरारत ("ओह हनी", "साहसी कदम")।
- **अराजक** - जमीनी वाक्य, फिर अचानक बेतुका मोड़ ("रिपोर्ट के अनुसार...")।
- **ज़ूमर** - गंभीर रूप से ऑनलाइन, क्रूर जेन-जेड व्यंग्य (प्रतिक्रिया, ताना, CAPS BLOCK, टैग)।

सभी मूड एमसीपी-वॉइस-साउंडबोर्ड (पाइपर अनुशंसित) के माध्यम से आवाज + लय को प्राप्त करते हैं।

### डॉकर

प्रत्येक रिलीज़ पर एक कंटेनर छवि जीएचसीआर पर प्रकाशित की जाती है। सेंसर-ह्यूमर एसटीडीआईओ पर एमसीपी का उपयोग करता है, इसलिए इसे इंटरैक्टिव रूप से चलाएं और इसे एक सुलभ ओलामा पर इंगित करें:

```bash
docker run -i --rm -e OLLAMA_HOST=http://host.docker.internal:11434 \
  ghcr.io/mcp-tool-shop-org/sensor-humor:latest
```

### अपने एमसीपी क्लाइंट को कॉन्फ़िगर करें

अपने क्लाइंट के एमसीपी कॉन्फ़िगरेशन में सेंसर-ह्यूमर को एसटीडीआईओ सर्वर के रूप में पंजीकृत करें। क्लाउड कोड / क्लाउड डेस्कटॉप (`claude_desktop_config.json`) या किसी भी `mcpServers`-आकार के कॉन्फ़िगरेशन के लिए:

```json
{
  "mcpServers": {
    "sensor-humor": {
      "command": "npx",
      "args": ["-y", "@mcptoolshop/sensor-humor"],
      "env": {
        "SENSOR_HUMOR_MODEL": "qwen2.5:7b",
        "OLLAMA_HOST": "http://127.0.0.1:11434"
      }
    }
  }
}
```

सर्वर इस `env` ब्लॉक (या उस शेल से) से अपना कॉन्फ़िगरेशन पढ़ता है जो इसे लॉन्च करता है - यह `.env` फ़ाइल को स्वचालित रूप से लोड नहीं करता है। समर्थित सभी चर के लिए [`.env.example`](.env.example) देखें। यदि आपने पैकेज को वैश्विक रूप से स्थापित किया है, तो `"command": "sensor-humor"` का उपयोग करें, `args` के बिना।

## त्वरित शुरुआत

1. ओलामा शुरू करें:

```bash
ollama pull qwen2.5:7b
```

2. सेंसर-ह्यूमर एमसीपी सर्वर शुरू करें (एसटीडीआईओ परिवहन):

```bash
cd sensor-humor
SENSOR_HUMOR_DEBUG=true npm start
```

3. वॉइस-साउंडबोर्ड शुरू करें (पाइपर मोड):

```bash
cd ../mcp-voice-soundboard
VOICE_SOUNDBOARD_ENGINE=piper VOICE_SOUNDBOARD_PIPER_MODEL_DIR=/path/to/piper/models npm start
```

4. अपने एमसीपी क्लाइंट (क्लाउड कोड, कर्सर, आदि) में:
- दोनों सर्वर जोड़ें
- परीक्षण श्रृंखला:

```
mood_set(style: "roast")
roast(target: "800-line god function")
```

पाठ व्यंग्य लौटाया गया। यदि [mcp-voice-soundboard](https://github.com/mcp-tool-shop-org/mcp-voice-soundboard) भी कॉन्फ़िगर किया गया है, तो `voice_speak(mood: "roast")` इसे मूड-उपयुक्त पाइपर्स लय के साथ बोलेगा।

## उपकरण

सभी उपकरण सत्र से वर्तमान मूड प्राप्त करते हैं।

| उपकरण | हस्ताक्षर | विवरण |
|------|-----------|-------------|
| `mood_set` | `(style: string)` | सक्रिय मूड सेट करें (सूखा, व्यंग्य, अराजक, शरारती, निराशावादी, ज़ूमर)। |
| `mood_get` | `()` | वर्तमान मूड + चुटकुला गणना + सक्रिय मूड के लिए `allowed_techniques`। |
| `comic_timing` | `(text, technique?)` | हास्यपूर्ण तरीके से फिर से लिखें (तीन का नियम, भटकाव, वृद्धि, कॉलबैक, कम करके आंकना, ऑटो)। |
| `roast` | `(target, context?, technique?)` | वर्तमान मूड की आवाज में स्नेही व्यंग्य, 1-5 की गंभीरता लौटाता है। संदर्भ: कोड, त्रुटि, विचार, स्थिति। वैकल्पिक तकनीक ओवरले वर्तमान मूड के लिए मान्य होना चाहिए (अमान्य संयोजन अस्वीकार कर दिए जाते हैं)। |
| `heckle` | `(target, technique?)` | संक्षिप्त, तीक्ष्ण ताना। वैकल्पिक तकनीक ओवरले, समान मूड × तकनीक मैट्रिक्स जैसा कि व्यंग्य में है। |
| `catchphrase_generate` | `(context?)` | पुन: प्रयोज्य अंश बनाएं (सत्र में संग्रहीत)। |
| `catchphrase_callback` | `()` | सबसे अधिक उपयोग किए जाने वाले वाक्यांश का पुन: उपयोग करें (या शून्य)। |
| `running_gag` | `(setup, tag)` | एक आवर्ती अंश लगाएं जिसे साथी बाद में वापस बुला सकता है (सुरक्षा-गेटेड)। `SENSOR_HUMOR_GAG_MIN_DISTANCE` बार के बाद कॉलबैक उम्मीदवार बन जाता है; `SENSOR_HUMOR_GAG_MAX_FIRES` बार के बाद सेवानिवृत्त हो जाता है। |
| `debug_status` | `()` | लाइव बैकएंड स्वास्थ्य (ओलामा सुलभ, मॉडल खींचा गया), हल किया गया कॉन्फ़िगरेशन, फ़ॉलबैक/दर गणना और सत्र स्थिति। |
| `debug_chain` | `(limit?)` | पिछले एन प्रति-कॉल ट्रेस (उपकरण, मूड, इनपुट, प्रॉम्प्ट फ़िंगरप्रिंट, पुनः प्रयास, सक्रिय सत्यापनकर्ता, विलंबता) - एक कॉल पीढ़ी पाइपलाइन का पुनर्निर्माण करता है। |
| `session_reset` | `()` | सभी सत्र स्थिति रीसेट करें (मूड, चुटकुले, अंश, वाक्यांश, ट्रेस, टर्न काउंटर)। |

**निम्न गुणवत्ता वाला आउटपुट (टाइप किया गया, मशीन-शाखा योग्य):** जब कोई उपकरण वास्तविक मॉडल पीढ़ी नहीं लौटा सकता है, तो यह एक इन-वॉइस डिब्बाबंद पंक्ति और `degraded: true` और एक `degraded_reason` लौटाता है, जो एक उपभोग करने वाले एजेंट द्वारा पूरी तरह से शाखाबद्ध किया जा सकता है: `safety-filter` (एक गाली/उपमा/मेटा-लीक को प्रतिस्थापित किया गया था) · `language` (मॉडल लैटिन लिपि से बाहर स्विच हो गया और एक अंग्रेजी पंक्ति को प्रतिस्थापित किया गया - एक अनुरूपता गिरावट, सुरक्षा नहीं) · `connection` · `timeout` · `model-not-found` · `auth` · `rate-limit` · `server` · `http` · `json-parse` · `validation` · `exhausted` · `unknown`। एक वास्तविक पीढ़ी में **कोई** `degraded` ध्वज नहीं होता है - इसकी अनुपस्थिति सकारात्मक संकेत है। **सभी** हास्य उपकरण इसे ले जाते हैं, जिसमें `catchphrase_callback` (एक सुरक्षा-प्रतिस्थापित स्मरण को चिह्नित किया जाता है, इसे कभी भी वास्तविक के रूप में नहीं बताया जाता है) शामिल है। `roast`/`heckle` सक्रिय `mood` को भी प्रतिध्वनित करते हैं; `catchphrase_generate` `is_fresh` लौटाता है (`true` = नया, `false` = एक मौजूदा सत्र वाक्यांश का पुन: उपयोग)।

एक ही कॉल में स्वास्थ्य संबंधी जानकारी प्राप्त करने के लिए `debug_status` पर कॉल करें: लाइव उपलब्धता (साथ ही `unreachable_reason` जब अनुपलब्ध हो - `connection` बनाम `auth` बनाम `timeout`), हल किया गया मॉडल/होस्ट/टाइमआउट, जनरेशन आंकड़े जिसमें `fallback_calls` (बैकएंड) **और** `safety_filter_fires` (कितनी बार सुरक्षा प्रणाली ने एक पंक्ति को बदल दिया) दोनों शामिल हैं, और एक `prompt_fingerprint` + `active_prompt_key` जो *सक्रिय* प्रॉम्प्ट टेक्स्ट + मॉडल को जोड़ता है ताकि आउटपुट में बदलाव को प्रॉम्प्ट-बनाम-मॉडल परिवर्तन के लिए जिम्मेदार ठहराया जा सके - और एक मौन प्रॉम्प्ट-संस्करण डाउनग्रेड (एक अनुरोधित v2 जो v1 पर वापस आ गया) दिखाई देता है।

## पर्यावरण चर

```bash
# sensor-humor
SENSOR_HUMOR_DEBUG=true                # verbose prompt/response dumps
SENSOR_HUMOR_TIMEOUT_MS=30000          # Ollama call timeout in ms (default: 30000; invalid values fall back to default)
SENSOR_HUMOR_TEMPERATURE=0.55          # generation temperature, clamped 0.0-2.0 (default: 0.55)
SENSOR_HUMOR_PROMPT_VERSION=1          # prompt set version (dry.v2 is the exemplar; set 2 to load v2 where it exists, else per-mood v1 fallback)
SENSOR_HUMOR_MODEL=qwen2.5:7b         # Ollama model (default: qwen2.5:7b)
SENSOR_HUMOR_PERSIST=false             # persist session to ~/.sensor-humor/session.json (survives restart; 24h expiry)
SENSOR_HUMOR_SESSION_DIR=              # override the session directory (default: ~/.sensor-humor)
SENSOR_HUMOR_MAX_RETRIES=1             # Ollama generation retries on bad output (0-3; default: 1)
SENSOR_HUMOR_GAG_MIN_DISTANCE=2        # turns before a planted running_gag is callback-eligible (default: 2)
SENSOR_HUMOR_GAG_MAX_FIRES=3           # times a running gag fires before it retires (default: 3)
SENSOR_HUMOR_FULL_TRACE=false          # debug_chain also captures full prompt/raw/parsed text (default: false)
OLLAMA_HOST=http://127.0.0.1:11434    # Ollama API host (default: http://127.0.0.1:11434)
OLLAMA_API_KEY=                        # Bearer token for a remote/cloud Ollama (e.g. https://ollama.com); unset for local

# voice integration (in voice-soundboard)
VOICE_SOUNDBOARD_ENGINE=piper          # or kokoro (default)
VOICE_SOUNDBOARD_PIPER_MODEL_DIR=/path/to/piper/models
```

## निगरानी और डिबगिंग

- प्रत्येक टूल कॉल लॉग करता है: भेजा गया प्रॉम्प्ट, कच्चा ओलामा प्रतिक्रिया, पार्स किया गया आउटपुट, सत्र अपडेट
- वॉइस: डिबग लॉग प्रत्येक मूड के लिए लागू पाइपर पैरामीटर दिखाते हैं
- सब कुछ देखने के लिए `SENSOR_HUMOR_DEBUG=true` सेट करें

## गुणवत्ता नोट्स

- कॉमेडी की गुणवत्ता कंकाल-आधारित प्रॉम्प्ट इंजीनियरिंग से आती है, न कि किसी एक मॉडल नॉब से - प्रत्येक मूड एक अनुमानित आकार को मजबूर करता है। अपने स्वयं के मॉडल/हार्डवेयर पर `scripts/ab-scorecard.ts` (SCORECARD.md में टेम्पलेट) के साथ हिट दर को मापें
- प्रॉम्प्ट-स्थिरता प्रतिगमन गेट (v1.2): v1 मूड प्रॉम्प्ट **स्थिर** हैं (`tests/scorecard-frozen-prompts.test.ts` द्वारा पिन किया गया - इसे बदलने के लिए, `v2` पर अपग्रेड करें, कभी भी सीधे संपादित न करें)। एक नियतात्मक **रूप + सुरक्षा** गोल्डन सेट + आंकड़े `npm test` में चलते हैं (कोई बैकएंड नहीं); `npm run scorecard` लाइव सांख्यिकीय विचलन जांच चलाता है - प्रति-मूड हिट-दर एक विल्सन अंतराल पर गेटेड है जिसमें तीन-मूल्य वाली PASS / FAIL / INCONCLUSIVE राय है और SPRT प्रारंभिक-रोक। यह संरचनात्मक अनुरूपता + सुरक्षा को मापता है, **न कि** हास्य (स्वचालित हास्य स्कोरिंग अविश्वसनीय है - सर्वश्रेष्ठ LLM-बनाम-मानव सहसंबंध ≈0.2)
- उपमा/तुलना फ़िल्टर: पोस्ट-वैलिडेशन रेगुलर एक्सप्रेशन + पुनः प्रयास, फिर यदि कोई रिसाव बना रहता है तो एक मूड-वॉइस सुरक्षित फ़ॉलबैक
- भाषा-अनुरूपता फ़िल्टर: कॉमेडी अंग्रेजी में है, इसलिए एक गैर-लैटिन-स्क्रिप्ट गेट (एक सन्निहित विदेशी-शब्द रन **या** एक उच्च गैर-लैटिन अक्षर अनुपात, केवल अक्षरों पर गणना की जाती है) कोड-स्विच किए गए आउटपुट को चिह्नित करता है - उदाहरण के लिए, `qwen2.5:7b` जो मध्य-पंक्ति में चीनी में बदल जाता है। पोस्ट-वैलिडेशन + एक अंग्रेजी-केवल पुनः प्रयास, फिर `degraded_reason: language` (एक *अनुरूपता* गिरावट, `safety-filter` से अलग, इसलिए यह सुरक्षा-फ़िल्टर फायर काउंटर के खिलाफ नहीं गिना जाता है) के साथ एक इनपुट-मुक्त अंग्रेजी फ़ॉलबैक। केवल-पता लगाने वाला - उच्चारणित लैटिन उधार शब्द (`café`, `résumé`), विराम चिह्न, अंक और इमोजी कभी भी इसे ट्रिगर नहीं करते हैं
- कठोर-भाषा फ़िल्टर: एक नियतात्मक शब्द-सूची रेगुलर एक्सप्रेशन प्रत्येक कॉमेडी टूल (कैचफ्रेज़ सहित) पर एक *अंतिम गेट* के रूप में चलता है, प्रत्येक पुनः प्रयास के बाद फिर से जांच की जाती है और किसी भी फ़ॉलबैक को लागू करने से पहले लागू किया जाता है। पहचान पथ पहले डी-ऑब्फस्केट करता है - NFKC + शून्य-चौड़ाई/बिडी स्ट्रिप + होमोलीफ़ फ़ोल्ड + लीट्सपीक फ़ोल्ड + इंट्रा-वर्ड-सेपरेटर स्ट्रिप + कॉम्बाइनिंग-मार्क स्ट्रिप - ताकि सामान्य बचाव (शून्य-चौड़ाई सम्मिलन, सिरिलिक/ग्रीक दिखने वाले, फुलविड्थ, `r3tard`, `re-tard`, `retárd`) शब्द सीमा को पार करने से अपमानजनक शब्द को न आने दें। यह एक नियतात्मक **न्यूनतम** है, न कि एक गार्डरेल - ईमानदार छत के लिए सुरक्षा और विश्वास देखें
- नियतात्मक: JSON स्कीमा प्रवर्तन, खराब आउटपुट पर पुनः प्रयास, सभी टूल में मूड विरासत लागू
- वॉइस: पाइपर प्रत्येक मूड के लिए प्रोसोडी पृथक्करण देता है; कोकोरो फ़ॉलबैक केवल गति है
- केवल देव-टूल साइडकिक। हास्य व्यक्तिपरक है; यदि आवश्यक हो तो किसी भी मूड को पर्यावरण के माध्यम से अक्षम करें या प्रॉम्प्ट को ट्यून करें

## सुरक्षा और विश्वास

- **डिफ़ॉल्ट रूप से स्थानीय** — `localhost` के माध्यम से HTTP के ज़रिए ओलामा से संवाद करता है। `OLLAMA_HOST` किसी अन्य स्थान (जैसे, एक रिमोट/क्लाउड ओलामा) की ओर इंगित कर सकता है; यह एकमात्र बाहरी आउटपुट है और यह ऑपरेटर की स्पष्ट पसंद है।
- **फ़ाइल सिस्टम** — डिफ़ॉल्ट रूप से कोई नहीं। `SENSOR_HUMOR_PERSIST=true` के साथ, यह एक फ़ाइल, `~/.sensor-humor/session.json` (`SENSOR_HUMOR_SESSION_DIR` के साथ निर्देशिका को ओवरराइड करें) पढ़ता/लिखता है, जिसमें केवल आपके सत्र की कॉमेडी स्थिति (बिट्स, चुटकुले, वाक्यांश) होती है — कोई क्रेडेंशियल नहीं। फ़ाइल 24 घंटे के बाद स्वचालित रूप से समाप्त हो जाती है।
- **गुप्त जानकारी** — डिफ़ॉल्ट रूप से कोई नहीं। यदि आप `OLLAMA_HOST` को एक रिमोट/क्लाउड ओलामा की ओर इंगित करते हैं, तो `OLLAMA_API_KEY` सेट करें; यह पर्यावरण से पढ़ा जाता है और केवल उस होस्ट पर एक `Bearer` हेडर के रूप में भेजा जाता है — कभी भी लॉग नहीं किया जाता, संग्रहीत नहीं किया जाता, या प्रतिध्वनित नहीं किया जाता (`debug_status` केवल यह रिपोर्ट करता है कि कोई कुंजी सेट है या नहीं, कभी भी इसका मान नहीं)।
- **कोई टेलीमेट्री नहीं** — कुछ भी एकत्र या भेजा नहीं जाता है।
- **सत्र स्थिति डिफ़ॉल्ट रूप से मेमोरी में होती है** — जब सर्वर प्रक्रिया बंद हो जाती है तो यह समाप्त हो जाती है; `SENSOR_HUMOR_PERSIST` के साथ डिस्क पर बने रहने का विकल्प चुनें।
- **इनपुट सैनिटाइजेशन** — प्रॉम्प्ट इंजेक्शन से पहले सभी उपयोगकर्ता-प्रदत्त टेक्स्ट को सामान्यीकृत और सैनिटाइज किया जाता है: यूनिकोड NFKC फ़ोल्ड, शून्य-चौड़ाई/द्विदिश/फ़ॉर्मेट वर्ण हटाए गए, सामान्य होमोोग्राफ़ को ASCII में बदल दिया गया, नई लाइनें हटा दी गईं, नियंत्रण वर्ण हटा दिए गए, लंबाई सीमित।
- **आउटपुट फ़िल्टरिंग (निर्धारित न्यूनतम + ईमानदार अधिकतम)** — एक बेस64-संग्रहीत टर्म-लिस्ट रेगुलर एक्सप्रेशन प्रत्येक कॉमेडी टूल पर एक टर्मिनल सुरक्षा गेट के रूप में चलता है (प्रत्येक पुन: प्रयास के बाद फिर से जांच की जाती है, किसी भी फ़ॉलबैक से पहले लागू किया जाता है), और एक कॉलर-इनपुट फ़ॉलबैक एक स्थिर, इनपुट-मुक्त पंक्ति में बदल जाता है, बजाय प्रतिबंधित टोकन को प्रतिध्वनित करने के। पहचान पथ पहले डी-ऑब्फस्केट करता है, इसलिए सामान्य बचाव विफल हो जाते हैं: शून्य-चौड़ाई/द्विदिश सम्मिलन, होमोोग्राफ़ (सिरिलिक/ग्रीक/पूर्ण-चौड़ाई), लीट्सपीक (`r3tard`), इंट्रा-वर्ड विभाजक (`re-tard`, `r.e.t.a.r.d`), और संयोजन डायक्रिटिक्स (`retárd`)। दूषित प्रविष्टियों को लोड होने पर छेड़छाड़/विरासत वाले सत्र से भी हटा दिया जाता है। **यह क्या नहीं करता:** यह एक निर्धारित टर्म-लिस्ट फ़िल्टर है, न कि एक सीखा हुआ क्लासिफायर — यह सूची से बाहर/नए अपमानजनक रूपों, एकल-अक्षर रिक्ति (`r e t a r d`), ASCII-कला / स्थानिक अस्पष्टता, पूर्ण यूनिकोड-भ्रमित कवरेज, या सिमेंटिक/जेलब्रेक-क्लास हमलों से बचाव नहीं करता है। इसे एक स्थानीय देव-हास्य उपकरण के लिए सर्वोत्तम-प्रयास न्यूनतम के रूप में मानें, न कि अविश्वसनीय सार्वजनिक इनपुट के लिए मॉडरेशन गारंटी के रूप में।
- **टूल त्रुटि आकार** — रनटाइम/टूल त्रुटियां स्टूडियो स्ट्रक्चर्ड एरर शेप (`{code, message, hint, retryable}`) लौटाती हैं; ध्यान दें कि *इनपुट-स्कीमा* सत्यापन त्रुटियां (जैसे, एक अमान्य `mood`) हैंडलर के चलने से पहले MCP SDK द्वारा पकड़ी जाती हैं और SDK की मानक `InvalidParams` त्रुटि के रूप में सामने आती हैं, न कि इस आकार में।

## आर्किटेक्चर

```
Host LLM (Claude, etc.)
  | calls tool
  v
sensor-humor MCP server (TypeScript, stdio)
  | builds mood prompt + session state
  v
Ollama (qwen2.5:7b-instruct, local)
  | returns JSON (schema-enforced)
  v
sensor-humor validates -> updates session -> returns to host
  | host optionally calls
  v
mcp-voice-soundboard (Piper backend)
  | maps mood -> prosody preset
  v
Piper TTS (local ONNX) -> audio
```
